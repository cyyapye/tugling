# Synthetic volunteer event

Coordinators use the plan throughout an event to see which stations need coverage
and adjust the station details. Every station has a name, optional note, contact
channel and contact address. A contact channel is either email or SMS; those
channels use an email address or a phone number respectively. Event and station
names are required. Notes are optional. Coordinators create and revise stations,
and save their plan in this browser. Plan ID is support metadata.

Use the existing synthetic record and preserve its identity. Only index.html is
the deliverable. Keep it self-contained, with no network, packages, sign-ins,
production data or Git commits. A browser capable of pointer and keyboard actions
must be supplied before live admission. Ordinary edits are authorized by the task.
