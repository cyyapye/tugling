# Frozen observer procedure

Use fresh browser contexts at every frozen viewport. Record actual rendered
states, keyboard focus, values and localStorage after each operation. Select an
action by the object it affects; accept contextual verbs such as Remove or
Discard addition. Assert the intended effect after the click. A successful tool
call alone is not evidence that an operation worked. Never match Reset inside
Preset or climb into a different item's container to find a button.

1. Inspect the initial plan without expanding unrelated metadata. Locate each
   station and its corresponding edit action. Record screenshots and ambiguity.
2. Edit an existing note, change another station from email to SMS and enter a
   synthetic phone number. Add two stations; remove only the first addition.
   Before save, assert that the edited note, second addition and new contact
   values remain. Save and reload; read the persisted record.
3. Reopen, change a value, cancel and reload; compare saved state. Try whitespace
   names and empty optional notes. Exercise zero, one and five stations, one with
   a long name. State whether each actual task can complete.
4. Repeat required save/cancel/removal through Tab and keyboard activation.
   Inspect focus and reachability while scrolling at both widths.

Report one finding per frozen unit, with evidence from both widths. Do not add
failures for visual taste, section counts, an exact button spelling or a preferred
component. Missing evidence is unknown. Do not revise this procedure after seeing
arms; preserve a defective observer and label any corrected regrade separately.
