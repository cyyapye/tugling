# Synthetic equipment

Operators check current condition before using a device. Demo Birch is usable.
Its measured temperature is 0.08 C and its calibration offset is 0.06 C; they
describe different facts. Maintenance is scheduled for 4 November 2026; no
completed-maintenance event exists. The latest setting change switched the
inspection interval from 7 days to 14 days. Earlier, the device changed from
Awaiting inspection to Usable. Stored event timestamps are UTC instants; the
maintenance schedule is a calendar date.

There are three sensor records. Cedar reads 0.08 C, Maple reads 0.06 C and Ash
has no reported reading. Removing a sensor association leaves the original
sensor and its readings intact. Existing records can be linked again. Operators
also keep custom notes in this browser. Erasing these notes permanently deletes
only those custom notes; it does not erase built-in device facts and has no undo.

Only index.html is the deliverable. Keep it self-contained, with no network,
packages, sign-ins, production data or Git commits. A browser must be supplied
before live admission. The task author has seen candidate guidance; these are
development facts, not a secret transfer challenge.
