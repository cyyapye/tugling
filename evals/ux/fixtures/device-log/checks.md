# Frozen observer procedure

At each frozen width use a fresh context. Capture the initial view and find
current usability, latest relevant change and each sensor's reading. Inspect
actual individual history entries and date/precision/unknown meanings. Equivalent
calendar formats, concise labels and different layouts are accepted.

Use pointer and keyboard to inspect a linked record, remove only its association,
reload and inspect storage. Assert the underlying sensor records and readings
remain, then re-link and reload. Exercise long names and five associations.
Record actual outcomes; matching a button or completing a command is insufficient.

Start note erasure; inspect the loss explanation before consent. Cancel and
reload, comparing notes. Confirm erasure in a new attempt, reload and assert the
custom notes are empty and built-in facts unchanged. Do not count confirmation
for irreversible erasure as needless friction. Do not invent an undo requirement.

Save screenshots, keyboard-focus and storage observations with concrete findings
for both widths. Count each underlying issue once. Visual taste and newly invented
requirements are not corrections. Unknown evidence is not a pass.
