# App conventions

Shared presentation belongs in `ui/`. Page-specific data and business actions
stay in `pages/`. Keep the current React and CSS stack. Component changes require
keyboard, empty/error state, and desktop/mobile checks. The source excerpt has
no installed runtime or screenshot evidence; do not infer visual acceptance.

`docs/component-review.md` is the current reuse backlog. Assessment requests are
read-only unless the user asks to save a report or implement changes.
