# Interface contract

The desktop summary and holdings list share one centered outer rail. At narrow
widths, holdings switch from a multi-column table to stacked rows; the page must
not scroll horizontally. Structural responsive behavior is fixed before spacing
tokens are tuned.

Material changes require inspected desktop and mobile screenshots plus the
interaction test for the row action. A baseline may be updated only after the
new image is intentionally correct, and the visual test must then pass again
without update mode.
